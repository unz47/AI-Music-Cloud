# AI Music Hub - アイデアメモ 💡

## コアコンセプト

- AI生成音楽に特化したオープンな共有プラットフォーム
- 誰でもSuno/Udio等で作った曲を気軽に投稿・共有できる
- SoundCloudのUI/UX + NCSのダークテーマ・ジャンル分けの世界観

---

## 機能アイデア

### 楽曲ブラウジング
- ジャンル別フィルター（Pop, Rock, EDM, Lo-Fi, Jazz, Classical...）
- 新着順 / 人気順 / トレンドのソート
- TrackCardグリッド表示（アートワーク、曲名、アーティスト、ジャンルバッジ）
- 無限スクロール or ページネーション

### 音楽プレイヤー
- フッター固定の再生バー
- 再生/一時停止、前へ/次へ、プログレスバー、音量調整
- キューイング（次に再生する曲のリスト管理）

### 楽曲投稿
- 音声ファイルアップロード（mp3/wav）
- メタデータ入力（曲名、ジャンル、タグ、説明文）
- アートワーク画像アップロード
- 生成ツール選択（Suno / Udio / その他）
- プロンプト共有（任意）— どんなプロンプトで生成したか

### 認証
- サインアップ / ログイン
- ソーシャルログイン（Google等）
- ゲストでも視聴可能、投稿にはログイン必須

### 検索
- キーワード検索（曲名、アーティスト名、タグ）
- ジャンル + ムード等の複合フィルター

### ユーザープロフィール・ソーシャル
- プロフィールページ（投稿した曲一覧）
- いいね機能 / いいねした曲一覧
- フォロー機能

### SoundCloudライクなUI要素
- 波形プレイヤー（曲詳細ページで波形表示、クリックでシーク）
- ストリーム（フィード）— フォロー中ユーザーの新曲タイムライン
- タイムドコメント — 曲の特定の時間に紐づくコメント
- リポスト — 他の人の曲を自分のフィードに再共有
- 横長Trackカードのリスト表示（アートワーク + 曲名 + 波形インライン）

---

### プレイリスト
- お気に入りの曲から自分だけのプレイリストを作成
- ドラッグ&ドロップで好きな順番に並び替え
- プレイリストの公開/非公開設定
- 他ユーザーのプレイリストも閲覧・再生可能

### 課金 / プレミアムプラン
- 無料ユーザー: ストリーミング再生のみ
- 有料ユーザー: プレイリストをオフラインダウンロード可能
- （検討）その他のプレミアム特典は？

## 開発フェーズ

### Phase 1: MVP — 聴ける・見つけられる（フロントエンドのみ）
- トップページ（楽曲一覧グリッド表示）
- ジャンル別フィルター
- フッター固定の再生バー（再生/一時停止、プログレスバー、音量）
- モックデータで動作確認
- ダークテーマ基盤

### Phase 2: 投稿できる
- ユーザー認証（サインアップ/ログイン）
- 楽曲アップロードフォーム（音声ファイル + メタデータ + アートワーク）
- 生成ツール選択・プロンプト共有
- S3連携（音声・画像ストレージ）
- バックエンドAPI（Lambda + API Gateway + DynamoDB）

### Phase 3: 見つける体験を強化
- キーワード検索
- ジャンル + ムードの複合フィルター
- 新着順 / 人気順ソート
- 曲の詳細ページ（波形プレイヤー）

### Phase 4: ソーシャル機能
- ユーザープロフィールページ
- いいね機能 / いいねした曲一覧
- フォロー機能
- ストリーム（フォロー中ユーザーの新曲フィード）
- コメント（タイムドコメント）

### Phase 5: プレイリスト & エンゲージメント
- プレイリスト作成（並び替え、公開/非公開）
- リポスト機能
- ランキング（週間/月間）
- 通知（いいね・コメント・フォロー）

### Phase 6: マネタイズ
- プレミアムプラン導入
- オフラインダウンロード（有料）
- その他プレミアム特典

## データモデル（DynamoDB想定）

### Users
| フィールド | 型 | 説明 |
|-----------|-----|------|
| userId | string (PK) | ユーザーID |
| displayName | string | 表示名 |
| avatarUrl | string | アバター画像URL |
| bio | string | 自己紹介 |
| plan | string | free / premium |
| createdAt | string | 登録日時 |

### Tracks
| フィールド | 型 | 説明 |
|-----------|-----|------|
| trackId | string (PK) | 楽曲ID |
| userId | string (GSI) | 投稿者ID |
| title | string | 曲名 |
| genre | string | ジャンル |
| tags | string[] | タグ（ムード、BPM等） |
| description | string | 説明文 |
| audioUrl | string | 音声ファイルURL (S3) |
| artworkUrl | string | アートワークURL (S3) |
| duration | number | 曲の長さ（秒） |
| aiTool | string | 生成ツール（Suno / Udio / 他） |
| prompt | string | 生成プロンプト（任意） |
| playCount | number | 再生回数 |
| likeCount | number | いいね数 |
| createdAt | string | 投稿日時 |

### Likes
| フィールド | 型 | 説明 |
|-----------|-----|------|
| userId | string (PK) | いいねしたユーザー |
| trackId | string (SK) | いいねされた曲 |
| createdAt | string | いいね日時 |

### Follows
| フィールド | 型 | 説明 |
|-----------|-----|------|
| followerId | string (PK) | フォローする側 |
| followeeId | string (SK) | フォローされる側 |
| createdAt | string | フォロー日時 |

### Comments
| フィールド | 型 | 説明 |
|-----------|-----|------|
| trackId | string (PK) | 対象の曲 |
| commentId | string (SK) | コメントID |
| userId | string | コメント投稿者 |
| content | string | コメント内容 |
| timestamp | number | 曲の何秒地点か（タイムドコメント） |
| createdAt | string | 投稿日時 |

### Playlists
| フィールド | 型 | 説明 |
|-----------|-----|------|
| playlistId | string (PK) | プレイリストID |
| userId | string (GSI) | 作成者 |
| title | string | プレイリスト名 |
| description | string | 説明 |
| isPublic | boolean | 公開/非公開 |
| trackIds | string[] | 曲IDの順序付きリスト |
| createdAt | string | 作成日時 |

## 画面 × データ対応表

| 画面 | 必要なデータ | 主なAPI |
|------|-------------|---------|
| トップページ | Tracks一覧（ジャンルフィルター、ソート） | GET /tracks?genre=&sort= |
| 曲詳細ページ | Track + User(投稿者) + Comments | GET /tracks/:id |
| ユーザープロフィール | User + そのユーザーのTracks一覧 | GET /users/:id |
| 検索結果 | Tracks（キーワード・フィルター一致） | GET /search?q=&genre=&mood= |
| フィード | フォロー中ユーザーのTracks（時系列） | GET /feed |
| プレイリスト詳細 | Playlist + 含まれるTracks | GET /playlists/:id |
| いいねした曲 | Likes → Tracks | GET /users/:id/likes |
| 投稿フォーム | — (書き込み) | POST /tracks |
| 再生バー | 現在再生中のTrack（クライアント状態） | — (フロント側で管理) |

## 競合との差別化（Suno等のコミュニティ機能との違い）

- **ツール横断** — Suno, Udio, その他どのツールで作った曲でもOK。特定ツールに縛られない
- **聴く体験に特化** — SoundCloud/NCSライクなリッチなプレイヤー、波形、プレイリスト。生成ツール側にはない体験
- **キュレーション** — ジャンル・ムード・ランキングで「いい曲を見つける」体験
- **プロンプト共有のハブ** — ツール横断でプロンプトのナレッジが集まる場所
- ポジショニング: Sunoは「作る場所」、AI Music Hubは「聴く・見つける・共有する場所」
